One original one-line office joke, written to `/output/entry.txt` by `main.py`,
for the [One-Line Office Joke Laugh-Off](https://make.fun/bounty/u-suzy-one-line-office-joke-laugh-off-f574ac73)
bounty on make.fun.

## The line

> HR said to bring my whole self to work, so I brought my resignation too.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The program is deterministic: it writes the same one line on every run.
The line is 72 characters, one line, plain UTF-8, inside the 1-200 character gate.
